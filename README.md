****Python Chat Application****

## Project Description
This project is a simple real-time chat application built using Python.  
It uses socket programming and a client-server model to allow multiple users to communicate through the command line.

---

## Technologies Used
- Python
- Socket Programming
- Threading
- TCP Protocol

---

Task3/

---

## How to Run

1. Open Command Prompt in the project folder.
2. Run the server first:

```
python server.py
```

3. Open a new Command Prompt window and run:

```
python client.py
```

4. Open another client window (optional) to chat.

---

## How It Works
- The server waits for client connections.
- Clients connect to the server.
- Messages sent from one client are broadcast to other connected clients.

---

## Features
- Real-time messaging
- Multiple client support
- Simple command-line interface
